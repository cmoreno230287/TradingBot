# TradingBot.Web

Angular Material dashboard for TradingBot.

## Run

```powershell
cd C:\Projects\TradingBot\TradingBot.Web
npm install
npm start
```

The current UI is a frontend shell for the trading workflow: broker status, strategy setup, chart visualization, command controls, risk guardrails, and reports. It is ready to be wired to a backend API that wraps the existing `TradingBot.CLI`/application services.
